# C++ Overlap Days Calculator

A C++ program that calculates the number of overlapping days between two date periods using date comparison and reusable date functions.

## Features

- Represent dates using structures
- Represent date periods using nested structures
- Compare two dates
- Check whether two periods overlap
- Calculate the number of overlapping days
- Handle leap years
- Calculate the number of days in a month
- Increase a date by one day
- Calculate the difference between two dates
- Use enums for date comparison results
- Use default parameters

## Main Concepts Practiced

- Structures
- Nested Structures
- Enums
- Functions
- Const References
- Boolean Logic
- Conditional Operator
- Default Parameters
- Date Comparison
- Period Overlap
- Date Manipulation
